# Manuscript Figures (`chart/`)

Reproduces all main-text and supplementary figures for Study 1 and Study 2 from the de-identified tabular datasets in `../data/` and the statistical outputs in `../statistical_analysis/outputs/`.

## Files
- `generate_publication_figures.py`: Standalone Python script that generates high-resolution (300 DPI) PNG figures into `./figures/`.
- `manuscript_figures.ipynb`: Interactive Jupyter notebook that runs `generate_publication_figures.py` and displays all generated figures inline.
- `figures/`: Output directory containing the generated PNG figures (`fig2_stai_subscales_and_rci.png` through `figS2_oof_scatter.png`).
